# TiViBro

IPTV/OTT-плеер для Android TV и планшетов, вдохновлённый TiViMate. Сетка телепрограммы с миниплеером, два движка воспроизведения, EPG, напоминания и история просмотров.

## Возможности

- **Два движка воспроизведения** — ExoPlayer (по умолчанию) и VLC (`libvlc-all`) как запасной; переключение в настройках, при сбое VLC автоматически пробуется ExoPlayer.
- **Сетка телепрограммы** — дни по горизонтали, каналы по вертикали, подсветка текущей передачи и линии текущего времени.
- **Миниплеер** — картинка канала живёт в телепрограмме; при включённой настройке «Оставаться в телепрограмме» канал запускается прямо в ней, а повторное нажатие того же канала разворачивает полноэкранный плеер.
- **EPG** — загрузка из XMLTV и встроенных источников, фоновая периодическая проверка, поддержка архивов gz
- **История** — недавно просмотренные каналы; канал попадает в историю только после заданного в настройках времени просмотра.
- **Поиск** — по каналам и VOD с историей запросов.
- **Плейлисты** — M3U, Xtream Codes и Stalker Portal; мастер добавления, обновление, скрытие, удаление.
- **Внешний вид** — светлая/тёмная/системная тема и масштаб шрифта.
- **Пульт** — настраиваемые действия для центральной кнопки и стрелок, подтверждение выхода вторым нажатием «Назад».
- **Автозапуск** — при загрузке устройства и при выходе из сна, включение последнего канала.
- **PIN-код** — защита запуска приложения и отдельных разделов.

## Требования

- Android 5.0 (API 21) и выше
- Для Android TV: пульт с D-pad; приложение работает и на планшетах с тачскрином

## Установка

Скачайте APK из [релизов](https://github.com/yar229/tivibro/releases) и установите на устройство

## Настройки

Все настройки находятся в разделе «Настройки» на главном экране. Основные группы:

- **Общие** — язык, внешний вид, обновление плейлистов, подтверждение выхода.
- **Плеер** — движок, буфер, декодер, перемотка, таймауты панелей, действия пульта.
- **Главный экран** — видимость каналов, подсветка, навигация, история.
- **Плейлисты и каналы** — сортировка, префиксы и суффиксы названий.
- **EPG** — смещение, глубина хранения, фоновая проверка.
- **История** — задержка добавления, количество недавних каналов.
- **Запуск** — автозапуск при загрузке и пробуждении, последний канал.
- **Данные и безопасность** — PIN-код, VOD в поиске.

## Web API

Плеером можно управлять по локальной сети: с телефона, с панели управления или из домашней автоматизации. Встроенный HTTP-сервер отдаёт состояние и принимает команды.

### Включение

Настройки → **Web API**:

- **Включить Web API** — запускает сервер. По умолчанию выключено.
- **IP-адрес** — адрес, на котором сервер слушает, показывает локальный IP устройства.
- **Порт** — по умолчанию `8080`.
- **API-ключ** — требуется в каждом запросе. Долгое нажатие копирует ключ в буфер обмена.
- **Сгенерировать API-ключ** — выпускает новый ключ, старый сразу перестаёт работать.
- **Документация по API** — открывает Swagger UI в браузере.

### Доступ и авторизация

Базовый адрес: `http://<ip-устройства>:<порт>/api`

Каждый запрос, кроме документации, должен нести ключ — в заголовке `X-API-Key` или в параметре `apikey`:

```
X-API-Key: <ключ>
```

Без ключа сервер отвечает `401` и ничего не делает.

> Ключ передаётся обычным HTTP в пределах локальной сети — он не шифруется. Держите сервер выключенным, если он не нужен, и не пробрасывайте порт наружу.

### Методы

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/status` | Что играет сейчас: канал, название и текущая передача |
| `GET` | `/api/channels` | Все каналы, у каждого — передача, которая идёт сейчас |
| `GET` | `/api/epg?id=<id>` | Программа канала на ближайшие 24 часа |
| `GET` | `/api/history` | История просмотров |
| `POST` | `/api/play?id=<id>` | Включить канал |
| `POST` | `/api/stop` | Остановить воспроизведение |
| `POST` | `/api/next` | Следующий канал в списке |
| `POST` | `/api/prev` | Предыдущий канал в списке |
| `POST` | `/api/remote?key=<клавиша>` | Нажать кнопку пута: `up`, `down`, `left`, `right`, `ok`, `back` |

Сервер разбирает запрос по пути, поэтому метод не проверяется строго — `GET` на `/api/play` сработает так же. В таблице указан метод из спецификации.

### Формат ответа

Время отдаётся в ISO 8601 с часовым смещением устройства, например `2026-10-02T12:00:00+03:00`. Клиенту не нужно знать зону плеера.

Текущая передача лежит в объекте `epg` с полями `title`, `subtitle`, `start`, `stop`. Если для канала в телепрограмме ничего нет, `epg` будет `null` — ключ всегда присутствует.

```json
{
  "playing": true,
  "channelId": 521,
  "channelName": "Первый канал HD",
  "epg": {
    "title": "Новости",
    "subtitle": "",
    "start": "2026-10-02T12:00:00+03:00",
    "stop": "2026-10-02T12:15:00+03:00"
  }
}
```

Ошибки возвращаются с соответствующим кодом и телом `{"error": "..."}`: `400` — не хватает параметра, `401` — нет или неверный ключ, `404` — неизвестный путь.

### Документация

Описание API в формате OpenAPI 3.0 отдаётся по адресу `http://<ip>:<порт>/api/openapi.json`, Swagger UI — на `/api/docs` и `/swagger`. Оба открываются без ключа.

### Примеры

```bash
# что играет
curl -H "X-API-Key: <ключ>" http://192.168.1.61:8080/api/status

# список каналов
curl -H "X-API-Key: <ключ>" http://192.168.1.61:8080/api/channels

# включить канал
curl -X POST -H "X-API-Key: <ключ>" "http://192.168.1.61:8080/api/play?id=521"

# следующий канал
curl -X POST -H "X-API-Key: <ключ>" http://192.168.1.61:8080/api/next
```
